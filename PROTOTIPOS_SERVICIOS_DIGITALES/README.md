## 🚀 Cómo Usar

### Abrir los Prototipos
1. Abre el archivo `index.html` en la carpeta raíz
2. Haz clic en cualquier "Ver Prototipo" para abrir el proyecto
3. Cada prototipo abre en una nueva pestaña

### Personalización
Todos los prototipos incluyen:
- **HTML**: Estructura fácilmente editable
- **CSS**: Estilos personalizables (variables de color, fuentes, etc.)
- **JavaScript**: Funcionalidad completa sin dependencias externas

## 🔧 Personalización Básica

### Cambiar Colores
La mayoría de prototipos usan gradientes predefinidos. Para cambiar:
1. Abre el archivo `style.css`
2. Busca `linear-gradient(135deg, #667eea 0%, #764ba2 100%)`
3. Reemplaza con tus colores preferidos

### Cambiar Textos
1. Abre el archivo `index.html`
2. Edita el contenido del HTML directamente
3. Guarda y actualiza en el navegador

### Agregar Funcionalidad
1. Edita el archivo `script.js`
2. Agrega JavaScript personalizado
3. Sin necesidad de compilar o construir
